# 保險報價整合系統（單機版）

這是一套以單一 HTML 檔案運作的保險報價整合工具，主要用於產險報價作業。系統目前整合三個模組：

1. 商業火災保險報價
2. 公共意外責任保險報價
3. 報價彙整表

本專案可直接用瀏覽器開啟使用，不需要安裝資料庫，也不需要部署後端即可操作基本功能。

---

## 專案特色

- 單檔 HTML，可直接開啟使用
- 支援商火報價單產生
- 支援公共意外險報價單產生
- 支援報價彙整表製作
- 支援列印或另存 PDF
- 支援輸出主題色切換
- 支援案件資料 `caseData` 流程
- 支援商火標的物多地址、多保額欄位
- 支援公共意外險多處所資料
- 支援保險公司報價輸入
- 客戶版彙整不顯示佣金資料

## 使用方式

### 1. 直接開啟

下載或複製本專案後，直接用 Chrome / Edge 開啟：

```text
保險報價整合系統_單機版.html
```

建議使用 Chrome 或 Edge。

---

### 2. 選擇功能

首頁提供三個入口：

```text
商火報價
公共意外險
報價彙整
```

---

### 3. 商火報價流程

1. 點選「商火報價」
2. 輸入要保人資訊
3. 輸入標的物地址與保額
4. 選擇自負額、天災比例、附加險
5. 勾選 SB 附加條款
6. 按「產生報價單」
7. 可列印或另存 PDF
8. 可儲存原始報價資料

---

### 4. 公共意外險流程

1. 點選「公共意外險」
2. 輸入要保人資訊
3. 輸入公共意外險處所資料
4. 輸入責任限額與自負額
5. 選擇附加條款
6. 按「產生報價單」
7. 可列印或另存 PDF
8. 可儲存原始報價資料

---

### 5. 報價彙整流程

1. 點選「報價彙整」
2. 搜尋或載入案件資料
3. 選擇新件或續保件
4. 輸入各家保險公司報價
5. 按「產生彙整報價單」
6. 匯出 Word 或列印 PDF

---

## 商火特殊輸入規則

商火保額欄位支援「含在其他欄位」的註記。

例如：

```text
營業裝修：35000000(含建築物)
```

輸出會顯示：

```text
建築物：含在營業裝修
營業裝修：35,000,000
```

五個保額欄位皆可互相標註：

```text
建築物
營業裝修
機器設備
營業生財
貨物
```

支援以下格式：

```text
35000000(含建築物)
35000000（含建築物）
35000000含建築物
35000000 ( 含 建築物 )
```

未填寫且未被包含的保額欄位，輸出會顯示：

```text
-
```

## 開發注意事項

修改時請注意：

1. 不要重做整個 UI
2. 不要破壞既有商火報價流程
3. 不要破壞公共意外險流程
4. 不要破壞報價彙整流程
5. 客戶版報價彙整不得顯示佣金、佣金率、佣金金額
6. 商火五個保額欄位的「含在」邏輯需保持一致
7. 空白保額欄位應顯示 `-`
8. 匯出或列印前請先測試預覽結果

## GitHub Pages 發布方式

1. 建立 GitHub repository
2. 上傳 `index.html`
3. 上傳 `README.md`
4. 到 Repository Settings
5. 找到 Pages
6. Source 選擇 `main` branch
7. Folder 選擇 `/root`
8. 儲存後等待部署完成

部署完成後即可取得公開網址。
